# homenu-panel

Panel de la factoría. Lee de GitHub los ficheros de cada proyecto (`config/<proyecto>.json`) y los enseña.
Corre en el servidor HoMenu-Panel (Hetzner), solo visible por la red privada Tailscale.

- `npm start` en local (puerto 8080, solo localhost) · `npm test`.
- Lo propio de cada proyecto vive en `config/`; el código no nombra MenuPlan.
- Issue de origen: pabloam89/MenuPlan#158.
